# Character Design Skill

`character-design` is a general character asset design skill for image and video workflows.

It helps create characters that remain recognizable across still images, character sheets, generated video, outfit variants, and multi-shot continuity. It is not limited to live-action, short drama, or any single genre.

## Use It For

- animation, game, film, commercial, mascot, creature, and live-action characters
- character cards and Character DNA
- height / proportion locks and body-silhouette preservation
- face, hair, mouth, hand, skin, and bone-structure anchors
- W0 front / side / back turnarounds
- expression rows and action-pose vocabulary
- wardrobe state ladders and costume variants
- permanent prop geometry and continuity
- relationship pressure, blocking roles, and ensemble contrast
- prompt anchors for image/video generation
- full asset-library character cards that stay separate from scene and prop cards

## Copy-Paste Requests

```text
Use character-design to create a production character packet for a short round courier: narrative function, height/proportion lock, face anchors, wardrobe states, signature prop geometry, turnaround contract, and video-readiness QC.
```

```text
Use character-design to redesign this reference character without changing their body type, height, face, mouth, hairstyle, costume category, or waist prop. Start with a proportion lock before making a final character sheet.
```

```text
Use character-design to build a cast of six fantasy academy roles. Make each silhouette, face structure, color anchor, posture, prop, and social function clearly different.
```

## Typical Outputs

- Compact character packet
- Proportion / height lock
- Face and hair anchor block
- Permanent prop geometry
- W0 turnaround contract
- Wardrobe state ladder
- Expression and posture range
- Relationship / blocking role
- Prompt-ready anchor block
- QC checklist and forbidden drift
